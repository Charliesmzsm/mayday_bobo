Mojo 萝卜桌宠 1.2.0 — 独立离线 Windows 版（本地构建）

Windows 10/11，.NET Framework 4.8。无需账号、网络、ChatGPT、Codex、Python 或 Node。
全部资源嵌入 EXE；同一会话只启动一只，安装版与便携版共享本机设置。

单击等待双击判定后招手；双击开心跳跃，偶尔星星眼惊喜。
惊喜至少冷却 3 分钟，滚动 10 分钟最多 2 次，手动触发也计入。
拖动移动并取消当前动作。右键桌宠/托盘打开菜单，选择动作、随机频率、60%–200% 大小。
自动情绪和眨眼关闭后保留轻呼吸；暂停全部动画冻结时间。隐藏/锁屏恢复不补播。
双击托盘显示并关闭穿透；召回到鼠标所在屏幕可找回桌宠。
默认开启注视与自动动作，关闭散步、登录启动和穿透。旧设置兼容，新字段默认为标准频率。

安装器仅安装当前用户，无需管理员权限。
程序：%LOCALAPPDATA%\Programs\MojoCarrotDesktop
设置：%APPDATA%\MojoCarrotDesktop\settings.xml
卸载：Windows 设置→应用，或开始菜单卸载入口；保留设置及用户额外放入的文件。
便携版直接运行 MojoCarrot.exe；启用登录启动后需保留 EXE 的原路径。

共 390 帧动作 + 16 个注视姿势。多数动作 24fps，呼吸 12fps。
素材为用户提供序列，未重画角色脸；惊喜嘴与舌头较平面，放大深色背景有轻微浅边。
当前机器验证通过；其他电脑、ARM64、真实锁屏与所有 DPI 组合未验证。
没有代码签名，运行前可核对附带的 SHA256SUMS.txt。
没有网络请求、遥测、自动更新、聊天或大模型功能。
尚未发布此版本至 GitHub；仓库 README 中 v1.0.0 下载仍为上一公开版本。
