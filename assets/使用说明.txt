Mojo 萝卜桌宠 1.0.0 — 独立 Windows 桌面版

运行环境：Windows 10 / Windows 11，.NET Framework 4.8（系统组件）。
无需 ChatGPT、Codex、Python、Node.js、账号、API Key 或网络。

使用方法
• 拖动萝卜：移动位置；透明区域不会挡住后面的窗口。
• 单击：叶片招手；双击：开心跳跃。
• 右键萝卜或任务栏托盘图标：切换动作、大小、注视、暂停、隐藏、退出。
• 托盘图标可能在任务栏的“显示隐藏的图标”箭头内。
• 双击托盘：显示桌宠并关闭鼠标穿透。
• “召回到鼠标所在屏幕”：找回被移动或隐藏的桌宠。
• 默认开启鼠标注视和偶尔做动作；默认关闭自动散步、开机启动和鼠标穿透。
• 大小可选 60%、75%、100%、125%、150%、200%。
• 共 9 种动作和 16 个注视方向，使用原有 Mojo 萝卜绒毛图片。

安装 / 卸载
安装器只安装到当前用户，不需要管理员权限。
程序目录：%LOCALAPPDATA%\Programs\MojoCarrotDesktop
设置目录：%APPDATA%\MojoCarrotDesktop
卸载：Windows 设置 → 应用 → Mojo 萝卜桌宠，或开始菜单中的卸载入口。
卸载保留个人设置，不删除用户额外放入程序文件夹的文件。
如需清空个人设置，请先退出桌宠，再删除上面的设置目录。

便携版
直接双击 MojoCarrot.exe。全部图片嵌入 EXE，不需要旁边放素材文件。
便携版开启“登录 Windows 时启动”后，请保持 EXE 的路径不变。
安装版与便携版共享当前用户设置，同一登录会话只显示一只桌宠。

隐私
程序没有网络请求、遥测、更新器、聊天或大模型功能。
设置保存在本机。安装包不包含自动更新功能。
