# v1.1.2：惊喜v2接入与透明边缘修正

日期：2026-10-22。程序、安装器和卸载器版本1.1.2.0。代码按用户要求提交到仓库；Release没有发布，README默认下载继续保留v1.0.0。v1.1.0/1.1.1本地交付包保留，不覆盖。

## 实际素材与实现

采用用户主交付frames_surprise48_v2_384x416，48张384×416 RGBA。逐帧与提供的18432×416图集核对，完全一致；无损打包为6张3072×416分页PNG。所有帧alpha与原惊喜完全一致，F01=F48且与原中性帧一致，底部锚点不变。12种动作共390帧，加16注视，总计406帧。47个不同像素图像不等于47个独立手绘姿势；开心停留中段仍主要是连续形变。

v2修整了嘴舌/星形材质，F08、F46、F47已经是小椭圆口，原有细横线不再使用。嘴形、舌头与星形变化均来自用户这批素材，未再次改画角色脸。文件来源、原文件/像素SHA256见ASSET-MANIFEST.json；各帧差异框见SURPRISE-V2-IMPORT.json。

单独提供的v2rim去边变体没有并入：它会改动锁定的中性帧，其余动作尚未统一，避免跨动作的边缘色彩跳变。它的存在不代表主交付已完成去边。

发现12组动作将预乘RGB写入PNG，GDI+默认直通读取会重复乘alpha。新增pages[].alpha_mode读取与校验，明确标记这12组为premultiplied，解码时还原一次；16向注视及旧图集保持straight，缺省仍为straight。同名共享页必须使用同一alpha_mode，未知值被拒绝。PNG原始像素保持，alpha也保持；修正只影响运行时对透明边缘颜色的解释。

源规格的24fps/2秒经校验，程序仍使用41/42ms累计2000ms时间表。来源loop=true仅用于素材预览，桌宠惊喜保持一次播放及既有冷却规则。正常速度GIF按累计10ms取整，实际48帧、2000ms；精确时序以程序/HTML为准。

- 完全离线构建成功。5418项自检通过，含旧素材自检与新增6项alpha读取/合成回归；可控时钟、固定随机种子、冷却、权重过滤、最近两次去重、暂停恢复、边界与完成事件仍通过。
- 实际打开Win32分层透明窗口，按正常速度播放12种动作和注视。惊喜实测2008ms。单/双击判定、拖动取消、模拟锁屏/暂停/隐藏、菜单、穿透召回、60/100/200%切换和移动边界通过。
- 安装器--verify、--test-install退出0，载荷中的程序/卸载器SHA256与最终构建一致。测试在隔离目录进行，不等于正式覆盖安装。
- 帧/页缓存峰值33,546,240/16,613,376字节，在32/16MiB预算内。自检GDI3→3，窗口初始化后两轮全帧绘制均GDI60；原生压力工作集165,076,992字节。正常播放18.725秒CPU2.016秒，约单核10.76%，压力段33.79%含集中绘制，不代表日常待机。
- Chrome实际正常速度播放2.3秒观察到全部48个帧索引，全部动作页可加载，无页面错误；60/100/200%深浅底分别截图。预览分页另存为标准直通PNG，以匹配运行时，未替换原资源。
- 实际打开全部48帧深浅底接触表、三种尺寸深浅底运行时采样图和用户前后对照。独立静态复核未发现需要回退的新增身份、双眼/双嘴、星形数量、透明洞、矩形背景、色块或裁切问题。眼距/眼圈、蓝眼底、每眼一颗四角星、三片主叶、缝线和身体轮廓维持同一角色。

## 仍可修整与验收限制

- surprise_star F12–F13、F42–F43：舌头从暗褐紫到亮粉的阶差仍明显，F13→F14/F41→F42需要细化。最小修复限这四帧舌头内部颜色和材质渐变，保持嘴形、眼睛、身体。
- F08/F47小口上缘仍略平，F07→F08及F47→F48在42ms内切换；静态阶段关系合理，连续播放的主观自然度仍需用户复核。不能据静态图宣称所有过渡完全自然。
- 星形出现/消退段仍读作暗金到亮黄；属于所提供v2素材，程序没有额外增星或改变星形数量。
- 200%深底仍可见共享叶片浅绿亮边，未见新增整圈白底。未对全部角色侵蚀alpha或统一去边。反预乘解码修复双乘暗边，并不能去掉源素材已有色相污染。
- 呼吸/蹦走的运动曲线未修改。边界包围盒1–2源像素差异不能单独证明循环缺陷，尚未以持续人工观看验收其全部接缝。

48帧仍包含察觉(F01–F10)、爆发(F11–F16)、开心停留(F17–F32)、余兴(F33–F40)、收势(F41–F48)；阶段有变化，但中段幅度克制，未增加新姿势或复制帧宣称提高帧数。

独立视觉结论只覆盖已打开静态图；自动正常速度播放验证不等于人眼持续观察全部动画，不能保证所有纹理闪烁都已排除。未执行真实锁屏、长期泄漏/功耗、跨机安装或所有DPI/多屏组合。最终代码保留可重复运行的--self-test与--smoke-test命令。

## 复现

运行powershell.exe -NoProfile -File build.ps1，生成build/MojoCarrot.exe、Uninstall.exe、MojoCarrot-Setup-1.1.2.exe。无NuGet或网络依赖。GUI诊断命令用Start-Process -Wait -PassThru等待退出，见README。局部美术提示词保留为历史参考；当前问题以本记录为准。
