# v1.2.0 注视与蹦走升级验证

2026-10-22。C# / WinForms / Win32 透明窗口；程序、安装器、卸载器均为1.2.0.0。

## 实现与来源

- gaze_grid_v2：81张384×416 straight-alpha姿势，9×9二维表；中心41号是中性。逐帧alpha相同，变化仅位于源坐标x140–238、y241–310的眼部；身体、嘴、缝线与叶片锁定。按鼠标相对位置与距离映射二维坐标，50ms时间常数平滑；取消旧版70ms候选等待。相邻已注册姿势进行亚像素采样，表情动作不会被普通注视覆盖。16向旧素材仍可兼容。
- hop_left/right_v2：每组48帧、47种不同像素图像，首尾相同。48帧是连续形变，不能称为48个独立手绘关键姿势。16/17ms累计时长精确800ms。用户曲线每步32逻辑像素，水平推进与选帧共用单调时钟；不重复叠加素材已经画好的竖直跳高。边缘缩短末次步幅，完整落地后结束；拖动即时取消。暂停/隐藏恢复不补播散步。
- 三组新素材均straight；其余10组动作保留premultiplied解码。所有519个运行帧裁图与素材清单像素SHA256一致；未重画角色。
- 程序检查周期8ms、注视绘制限约16ms，运行期间成对申请/释放Windows 1ms计时精度。实际显示仍受Windows调度、CPU和显示器影响，不能承诺每台电脑稳定60fps。
- 帧缓存32MiB、页缓存16MiB；注视复用输出和4个CPU采样缓冲也计入帧预算，不缓存全部尺寸。Bitmap/LockBits成对释放，HBITMAP/DC沿用原生绘制释放流程。

## 实际检查

- 离线构建成功。7692项断言通过，包含原自检、JSON拒绝测试、可控时钟及种子、冷却/权重过滤/最近动作去重、暂停恢复、完成事件、二维平滑响应与反向、不同检查频率一致性、步幅缩放和左右边界、三种尺寸的采样与预算检查。
- 新版原生窗口正常速度播放与交互冒烟通过：向右811ms、向左809ms，各观察到47/48个时间轴帧位。它们是实际本机观测，未把检查次数当作新帧，也未声称每轮无丢帧。注视路径连续采样3秒；全部情绪动作正常播放，单/双击、拖动取消、菜单、穿透恢复、模拟暂停/隐藏/锁屏、60/100/200%与边界检查通过。
- 原生正常播放20.307秒，CPU3.297秒（单核16.24%，包含轮流播放全部动作和注视路径，不代表日常待机功耗）。初始化后两轮全帧压力绘制GDI均为60；自检GDI3→3。帧/页峰值33546240/16613376字节，预算33554432/16777216。
- --legacy-smoke-test通过，旧16向资源和旧散步路径仍工作。安装器隔离测试通过载荷、快捷方式目标、卸载与用户额外文件保留，不改实际安装目录/注册。
- 离线Chrome预览实际播放左右往返、上下往返、绕圈及左右横移，各段约3.2秒；页面无错误，60/100/200%深浅底截图齐全。浏览器捕获到左右33/34个帧索引，未将此预览声称为满60fps；原生结果单列。
- 实际打开运行时200%采样图；独立视觉复核另打开中性、81姿势接触表、左右关键及全帧接触表和60/100/200%深浅底样张。静态pass：无新增双眼/双嘴、洞、裁切、身份漂移；蓄力、腾空、落地、收势可辨。

## 限制与残余

独立复核是静态检查；浏览器与原生正常速度运行记录证明播放/时序，并不等于人工持续观看全部动作，不据此保证所有纹理闪烁已排除。200%深底叶片原有浅绿亮边仍在，非新增阻断问题；后续若修仅限外沿半透明像素带。本批没有扩大眼神位移超过用户提供的2.6/2.9源像素，因此100%外观仍为克制的小幅注视。

未验证真实锁屏、跨机/ARM64、长期功耗/泄漏和全部多屏DPI组合。默认仍关闭左右散步；右键开启“允许左右散步”，或菜单手动选择向左/向右蹦走。此次交付提供源代码、安装版、便携版、校验文件与离线预览。发布是否成功以GitHub公开Release与下载资产核对为准。
