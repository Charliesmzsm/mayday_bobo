# Mojo 萝卜 v1.1.0 本地升级与验收记录

日期：2026-10-22。源码已在用户指定的 mayday_bobo 根目录就地修改。此次仅交付本地构建，未推送、未新建 GitHub Release；README 的默认公开下载仍为已经发布的 v1.0.0。

## 已实现

- C# / WinForms / Win32 分层窗口，完全离线、无运行时 Python/Node/NuGet 依赖。程序、安装器和卸载器均 1.1.0。
- 实际 JSON 读取与校验，按 actionId / frameIndex / 帧矩形 / 锚点访问分页资源。旧 8×11 图集仅由兼容适配器使用。建议稿与实际 schema 分开保存，修改实际 JSON 需要重新构建。
- Stopwatch 单调时间轴与可变帧时长。惊喜 48 帧累计 2000ms，41/42ms 交替近似 24fps，呼吸 12fps；16ms Timer 只是检查，不是素材帧率。UI 忙时跳过逾期画面，不补播堆积队列。
- 手动动作可打断，随机/微动作仅在待机启动，情绪脸不被中性注视覆盖。拖动立即取消；丢失鼠标捕获后能恢复。暂停/隐藏/锁屏/菜单冻结播放，恢复重新等待，不追赶错过的随机触发。
- 冷却、滚动窗口先过滤，再按 34/24/16/12/8/6 权重抽样；尽量排除最近两次随机动作，池不足仅放宽倒数第二次。惊喜冷却至少180秒、滚动10分钟最多2次，手动也计数。动作结束重新开始等待。
- 单击等待系统双击阈值，双击取消待决招手；菜单含全部动作、随机频率三档、旧版功能，XML 旧字段缺省兼容。
- 当前显示尺寸帧 LRU 32MiB、解码页 LRU 16MiB；换尺寸清空帧缓存。Bitmap/Graphics/临时图/托盘/事件订阅均释放；HBITMAP、兼容DC与屏幕DC在 finally 配对释放。

## 视觉检查范围与结果

已实际读取批准惊喜图、中性16方向、对照图、6关键帧和48帧接触表；打开了惊喜全部48帧的深浅底接触表，以及各动作60/100/200%运行时渲染首/中/尾采样图。实际启动了正常速度的原生播放和浏览器动画，并检查播放截图。上述检查不等于逐帧人工观看全部406帧的所有尺度组合；全帧几何/透明洞/像素一致性则执行了自动检查。

在已查看画面中，眼距与眼圈维持一致，蓝眼底保留；惊喜每只眼睛一颗黄色四角星，共两颗，没有看到叠加的第二双眼或第二张嘴。粉色舌头、三片主叶与既有折叠关系、缝线及绒毛身体保持同一来源。闭眼/打哈欠会按动作遮住蓝眼底，非资源遗漏。

全部406帧的主体未贴到画布边缘，未检出封闭透明洞或主体内部异常半透明洞。底部包围盒均保留安全边，统一源锚点[192,392]；跳跃允许离地，不会逐帧强制贴地。运行时先裁帧再缩放，未见相邻帧色块串入。已查看画面未发现明显色键背景残留、身体裁切、跨帧大色块或无意的大体型变化；细微纹理闪烁仍需人工持续观看确认。

各动作首尾均为中性表情或同一中性朝向，情绪结束后回呼吸。blink、wave、happy_bounce、surprise_star、sleepy_yawn、think首尾像素相同；leaf_fidget、curious_tilt、shy_squish首尾边界相同但存在亚像素变形差。呼吸循环接缝包围盒左右差1源像素（100%为0.5逻辑像素）；左右蹦走首尾叶冠/宽度最多约2源像素差。属于轻微接缝，未擅自重采样修画。gaze为独立方向集，本身不要求首尾同姿势。

### 仍需美术复核的最小范围

以下F编号从1开始，JSON frameIndex=F-1。没有把这些问题写成已修复。

- **surprise_star F10–F43（约0.375–1.792秒）**：星形边缘和黑嘴相对身体更平面，粉舌有规律竖纹；200%深底最明显，100%仍能看出。与批准静态图本身一致，不是渲染时产生。最小修复是这些帧的嘴/舌/星形局部材质，保留眼圈、蓝底、身体和缝线，修复后再审批；不要整只重画。
- **surprise_star F08、F46，连同F07–F11/F43–F47过渡段**：嘴从笑线到开口/收口经过过薄直线，转场有图形变形感。最小修复限嘴部过渡轮廓，不需要替换48帧身体，也不要在中间叠加中性嘴。
- **全部动作共享的叶冠外缘，尤其200%深底；例如wave F01/F21、surprise F01/F21**：有轻微浅色轮廓，60%不突出。需检查原图半透明边是否带浅色污染，最小范围为边缘约1–2源像素；当前无法仅凭视觉断言它一定是色键残留，不擅自去边侵蚀绒毛。
- **idle_breathe F32→F01；hop_right F24→F01；hop_left F24→F01**：微小包围盒接缝如上。最小范围为各自首尾2–4帧的位移/变形曲线，不能以重复帧冒充新增细节。

### 单独检查48帧惊喜

- F01–F07：中性进入察觉，有轻微预备变化；F08–F10：小嘴、星眼出现，察觉阶段较短。
- F11–F16：嘴/舌展开、星星提亮，完成爆发。
- F17–F32：星眼开心停留，伴随连续身体/叶片微变形，而非全段复制同一帧。
- F33–F40：余兴与较小的回弹；F41–F48：星眼消退、嘴收拢、回到中性。

结论：包含真实的阶段变化，47个不同图像，F01=F48；不是少数旧图集姿势重复。但中段变化主要为既有姿势的连续变形，不能宣称48个完全不同的独立关键姿势；余兴段与开心停留差异偏细，仍有提高表演幅度的空间。
