# 验证说明

v1.0.0 在 Windows 11（内核 10.0.26200）和 .NET Framework 4.8 系列验证。

- 图集 1536×2288，74 个有效格、14 个透明格；alpha 解码正常。
- 16 个方向索引、角度环绕与 60%–200% 尺寸切换。
- 原生透明窗口、9 种动作和全部注视方向。
- 单击/双击、隐藏/显示、穿透和托盘恢复。
- 中文安装界面与菜单人工检查。
- 安装包内应用和卸载器与构建文件 SHA256 一致。
- 隔离目录验证部署、快捷方式和只删除程序文件、保留用户文件。

未修改正式安装目录和卸载注册项；不等同于多机完整安装验证。尚未覆盖 ARM64、所有多显示器/DPI 配置和其他 Windows 版本。

## 诊断命令

编译后使用绝对输出路径，等待进程结束并查看报告，成功退出码为 0。

```text
MojoCarrot.exe --self-test <输出目录>
MojoCarrot.exe --smoke-test <报告文件路径>
MojoCarrot-Setup-1.0.0.exe --verify <输出目录>
MojoCarrot-Setup-1.0.0.exe --test-install <输出目录>
```

窗口测试会短暂显示桌宠和菜单。隔离安装测试不会注册正式卸载入口。
